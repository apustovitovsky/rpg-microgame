## Naming
Use the `SO` suffix only when a ScriptableObject name would conflict with a runtime type.

## VContainer
Prefer `AsImplementedInterfaces()` over explicit interface registration when VContainer can infer the intended closed interfaces.
В VContainer не имеет значение порядок регистрации.
